Rules written as triggers

TriggerFiresRule
trg_check_severityBefore an incident is added or changedSeverity outside 1 to 5 is refused
trg_enforce_investigationBefore an incident is addedSeverity 4 or 5 forces an investigation, status in progress
trg_check_worker_ageBefore a worker is addedUnder 18 is refused
trg_check_training_validityBefore training is recordedExpiry must follow the training date
trg_check_shift_capacityBefore a shift assignmentNo assignment past the shift’s maximum
trg_update_equipment_statusAfter usage is loggedEquipment marked in use
trg_maintenance_after_insertAfter maintenanceStatus and last-maintenance date updated
trg_transfer_after_insertAfter a transferOperator follows the equipment

One risk score per worker

Computed in PL/SQL by get_worker_risk_score, in the database beside the data it reads.

incidents × avg severity × 2+ shifts × 0.1+ equipment issues × 1.5

A Flask demo

The tables, ported to SQLite behind 28 routes. The triggers stay in Oracle; the demo checks worker age in Python.

Run it

Python 3.10 to 3.12. Open localhost:5000 and load the sample data. On a Mac, turn off AirPlay Receiver first; it holds port 5000.

git clone https://github.com/akshit9162/Underground-Mining_DBMS-Project
cd Underground-Mining_DBMS-Project/mining_app
python3.12 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python app.py
